# Contributing to PocketAuthor-Public

Thank you for helping improve PocketAuthor's public documentation and roadmap.

## Good public contributions

You can open issues for:

- feature ideas
- documentation corrections
- accessibility problems
- author workflow suggestions
- publishing integrations
- research and source workflows
- copyright/provenance ideas
- community programs
- public use cases
- broken public links

## Do not post sensitive material

Do not put any of the following into public GitHub issues:

- unpublished confidential manuscripts
- private interviews
- passwords or API keys
- personal identification data
- private customer information
- confidential company documents
- copyrighted material you do not have permission to republish
- legally privileged information

## Feature requests

A useful feature request should explain:

1. who the user is,
2. what they are trying to accomplish,
3. what currently makes that difficult,
4. the proposed workflow,
5. why the feature belongs in an authoring platform.

## Documentation corrections

Please include:

- the page or section
- what is unclear or incorrect
- the suggested correction
- sources where factual verification is needed

## Security or private disclosures

Do not disclose security issues publicly if doing so could put users or systems at risk. Use PocketAuthor's official private security/contact process once published in the canonical link directory.

## Scope

This public repository is a documentation, roadmap, community, and public-facing project surface. It is not necessarily the full PocketAuthor application codebase.
