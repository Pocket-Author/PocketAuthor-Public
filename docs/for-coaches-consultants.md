# PocketAuthor for Coaches and Consultants

The work you repeat for clients may contain a book.

Frameworks, diagnostics, exercises, workshop materials, case patterns, and client questions can become a practical guide—when confidentiality and evidence are handled carefully.

## From service work to book

- identify the repeatable method
- define the reader problem
- separate generalizable insight from private client material
- document frameworks
- add examples and exercises
- validate claims
- build a structured progression
- create a manuscript
- turn the book into workshops, training, speaking, and client education

## Book-to-business loop

A useful book can generate:

**reader trust → speaking/workshops → qualified conversations → client education → stronger methodology → second edition or next title**

PocketAuthor should help authors understand that the book is not only a publication. It can become reusable intellectual property.
