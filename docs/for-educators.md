# PocketAuthor for Educators

Educators can turn years of teaching into durable learning resources.

## Possible projects

- practical textbooks
- workbooks
- course companions
- teacher guides
- field manuals
- curriculum books
- community education resources
- institutional histories

## From course to book

PocketAuthor can help organize:

- learning objectives
- chapter sequence
- terminology
- examples
- exercises
- references
- review questions
- accessibility
- production requirements
- companion resources

The goal is a teaching artifact that can survive beyond one semester, one cohort, or one platform.
