# PocketAuthor Distribution Guide

A finished book still needs a path to readers.

## Common distribution paths

### Amazon KDP
Best for fast print and ebook availability.

PocketAuthor workflow opportunities:
- file validation
- metadata preparation
- edition setup guidance
- pricing checklist
- proof review

### IngramSpark
Useful for broader wholesale, bookstore, and library reach.

PocketAuthor workflow opportunities:
- production setup
- metadata
- discount and returns education
- print preflight
- edition tracking

### Direct sales
Useful for customer relationships, bundles, and margin control.

Potential workflow:
- landing page
- direct checkout
- fulfillment integration
- signed or bundled editions
- customer email capture

### Bulk and corporate sales
Useful for consultants, speakers, universities, associations, nonprofits, and companies.

Potential workflow:
- bulk edition strategy
- pricing
- proposal assets
- fulfillment
- corporate workshop bundle

### Course and community bundles
Useful for coaches and educators.

Combine:
- book
- workbook
- templates
- video lessons
- cohort access
- community membership

### Audiobook
Useful for spoken-word audiences.

Potential support:
- narration script preparation
- pronunciation notes
- chapter pacing
- metadata
- production tracking

### International and translation editions
Useful after demonstrated regional demand.

Potential support:
- rights tracking
- localization
- translator workflow
- edition management
- regional metadata

## Important

Distribution availability does not guarantee discovery, bookstore placement, retailer acceptance, reviews, or sales.
