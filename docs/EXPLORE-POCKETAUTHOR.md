# Explore PocketAuthor

PocketAuthor is more than a writing editor. The public product includes tools and directories for discovering a book idea, shaping the manuscript, researching publishing options, finding funding and literary events, preparing editions, and learning the practical work around authorship.

## The larger idea

PocketAuthor connects four worlds that authors usually manage separately:

**MAKE THE BOOK**
idea → source material → outline → draft → revision

**MAKE IT TRUSTWORTHY**
research → sources → fact checking → provenance → rights

**MAKE IT PUBLISHABLE**
metadata → formats → cover → proof → distribution

**MAKE IT MATTER**
grants → publishers → events → audience → marketing → opportunities

That is the product story the public documentation should reinforce.
