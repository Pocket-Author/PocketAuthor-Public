## Friendly SEO writing rules

1. Answer the reader's question before explaining PocketAuthor.
2. Use plain English.
3. Avoid repeating the same exact keyword unnaturally.
4. Link to the most relevant live product surface.
5. Give each page one primary search intent.
6. Add related questions naturally as headings.
7. State limitations and changing facts clearly.
8. Prefer specific examples over abstract AI claims.
9. Make pages genuinely useful even if the visitor never signs up.
10. Use PocketAuthor as the workflow continuation—not the entire answer.
