# Publishing Readiness

A finished draft is not automatically ready to publish.

## Manuscript readiness

- complete structure
- resolved placeholders
- consistent terminology
- edited prose
- fact-checked claims
- cleared quotations
- source review
- permissions tracked
- final notes/references

## Production readiness

- trim size selected
- print layout reviewed
- ebook flow tested
- images licensed and high-resolution
- fonts licensed
- front/back matter complete
- cover files prepared
- metadata complete
- ISBN decision made
- proof reviewed

## Commercial readiness

- clear reader positioning
- description
- author bio
- categories
- keywords
- price
- sales channels
- launch timeline
- ARC/reviewer plan
- direct-sales plan where relevant

## Important distinction

"Uploadable" is not the same as "professional."

PocketAuthor's publishing-readiness narrative should focus on reducing avoidable errors and making production requirements visible before launch.
