# 8. Formatting and Production

A manuscript becomes a publication through production.

## Production checklist

- front matter
- heading hierarchy
- table of contents
- notes
- bibliography
- figures
- tables
- image rights
- captions
- callouts
- trim size
- page breaks
- ebook flow
- print layout
- accessibility
- font licensing
- proof review
- audiobook script preparation

The goal is not merely a "finished document." It is a production-ready book package.
