# 9. Publishing

Publishing requires decisions beyond the manuscript.

## Publishing preparation

- title
- subtitle
- author name
- description
- author bio
- categories
- keywords
- ISBN strategy
- cover
- edition information
- copyright page
- pricing
- ebook files
- print files
- publisher/imprint information

## Publishing routes

- self-publishing
- traditional publishing
- hybrid publishing
- organizational publishing
- limited/private editions

Publishing availability, retailer acceptance, discoverability, and sales should never be treated as guaranteed outcomes.
