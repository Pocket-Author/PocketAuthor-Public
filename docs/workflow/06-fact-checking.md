# 6. Fact Checking

AI-assisted books need explicit fact review.

## High-risk claim types

Flag:

- dates
- statistics
- legal rules
- medical claims
- scientific claims
- historical claims
- quotations
- named people
- company facts
- prices
- rankings
- market data
- current events

## Useful claim statuses

- verified
- source attached
- needs source
- weak source
- disputed
- outdated
- opinion
- author recollection
- remove

A credible book should make it easier—not harder—to trace claims back to evidence.
