# PocketAuthor Feature Narratives

Features should be described in terms of what they help an author accomplish.

## Source Material

Live surface:
https://www.pocketauthor.com/source-material

### Narrative
**Start from what you already know.**

Bring notes, interviews, transcripts, documents, talks, research and existing content into the project so the book starts from real material instead of an empty prompt.

### Search language
- turn existing content into a book
- turn notes into a book
- turn podcast into a book
- turn research into a book
- turn expertise into a book

## The unifying feature story

PocketAuthor should not present these as disconnected tools.

The stronger story is:

**Discover the book → build it → verify it → assemble the right team → prepare editions → find funding and publishers → show up where readers gather → keep expanding the book after launch.**
