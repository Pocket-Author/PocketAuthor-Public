# PocketAuthor for Coaches

## Turn your coaching framework into a book people can use between sessions

A strong coaching book should not be vague inspiration.

It should help a reader move through a real transformation.

## Your existing source material may include

- coaching frameworks
- reflection prompts
- exercises
- workshop material
- client questions
- recurring patterns
- stories
- personal philosophy

## Good book structures

- transformation guide
- workbook
- framework book
- habit or practice system
- reflective journal
- course companion

## Workflow

1. Define the reader’s starting point.
2. Define the outcome.
3. Map the method.
4. Turn steps into chapters.
5. Add exercises.
6. Add examples without violating client confidentiality.
7. Build a workbook or course layer.
8. Publish and reuse the content.
