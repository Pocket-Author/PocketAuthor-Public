# PocketAuthor Acquisition Library

The PocketAuthor Acquisition Library is a public collection of practical, search-friendly pages for people trying to turn knowledge into books and navigate everything around publication.

The goal is simple:

**Answer the real question first. Then show the next useful PocketAuthor workflow.**
