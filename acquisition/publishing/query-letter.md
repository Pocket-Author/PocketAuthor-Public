# How to Write a Query Letter

A query letter is a concise pitch used to approach a literary agent or publisher when that submission route is appropriate.

## A query usually needs

- a clear hook
- what the book is
- who it is for
- why it matters
- relevant author credentials
- manuscript status
- requested materials

## Keep it specific

Avoid generic claims like “this book is for everyone.”

Use the recipient’s stated submission requirements.
