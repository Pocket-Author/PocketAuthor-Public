# How to Prepare Book Metadata

Book metadata is the structured information that helps retailers, libraries, distributors, and readers understand what a book is.

## Common metadata fields

- title
- subtitle
- author name
- contributors
- description
- categories
- keywords
- ISBN
- language
- publication date
- edition
- format
- price
- territories
- publisher or imprint

## Why metadata matters

Good metadata improves clarity and discoverability.

It does not guarantee sales.

## Workflow

1. Lock the title and subtitle.
2. Write a clear reader-focused description.
3. Choose categories that accurately fit the book.
4. Select useful search terms without keyword stuffing.
5. Confirm contributor names.
6. Review rights and territory information.
7. Keep metadata consistent across platforms.
