# What Is an EPUB and How Do You Prepare One?

EPUB is a common ebook format designed for reflowable reading across devices and apps.

## A good EPUB should handle

- chapter navigation
- table of contents
- headings
- paragraph flow
- images
- links
- accessibility
- metadata

## Review before distribution

- table of contents works
- chapter order is correct
- images render cleanly
- links work
- special characters display correctly
- headings are structured
- alt text is included where appropriate
- metadata is accurate
