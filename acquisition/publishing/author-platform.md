# What Is an Author Platform?

An author platform is the set of audiences, channels, relationships, credibility, and distribution paths an author can use to reach readers.

## It can include

- email list
- professional network
- social audience
- podcast
- speaking
- community
- clients
- institutional relationships
- media
- partnerships

## Platform is not follower count

A small, relevant audience can be more useful than a large, disengaged one.

## Build before launch

Start communicating the book’s ideas while the book is being developed.
