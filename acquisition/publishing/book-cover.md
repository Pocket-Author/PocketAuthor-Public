# How to Prepare a Book Cover

A book cover has to work as both design and production asset.

## Cover decisions

- title readability
- subtitle
- author name
- genre/category expectations
- thumbnail performance
- print dimensions
- spine width
- back cover
- barcode area
- image rights
- font licensing

## Test the cover

View it:

- as a thumbnail
- at full size
- in grayscale where useful
- beside comparable books
- as a print wrap if producing a physical edition
