# Amazon KDP vs. IngramSpark

KDP and IngramSpark are different publishing/distribution systems with different workflows, reach, economics, and policies.

## Compare

- print formats
- ebook distribution
- wholesale reach
- bookstore/library access
- discounts
- returns
- print cost
- setup requirements
- geographic availability
- account control

## Important

Platform policies and pricing can change.

Review current official documentation before making a publishing decision.
