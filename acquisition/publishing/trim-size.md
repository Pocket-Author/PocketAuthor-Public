# How to Choose a Book Trim Size

Trim size is the physical page size of a printed book.

## It affects

- page count
- typography
- spine width
- print cost
- visual feel
- portability
- bookstore presentation

## Choose based on

- book type
- reading experience
- amount of text
- illustrations/tables
- print provider options
- comparable books
- production economics
