# How to Prepare a Manuscript for Publishing

Finishing the draft is not the same as finishing the book.

## Manuscript readiness

Before production, review:

- structure
- chapter completeness
- editing
- proofreading
- facts
- sources
- quotations
- permissions
- references
- front matter
- back matter

## Production readiness

Decide:

- ebook
- paperback
- hardcover
- trim size
- paper
- bleed
- cover
- fonts
- images
- metadata
- ISBN
- pricing
- territories

## File readiness

You may need:

- EPUB
- print interior PDF
- print cover PDF
- cover image
- metadata sheet
- author bio
- book description

## Proof

Review:

- ebook preview
- print preview
- physical proof where relevant
- page breaks
- image quality
- table of contents
- headers/footers
- typography
- metadata
