# Publishing Is Not One Button

A finished manuscript still needs a chain of decisions.

## The chain

**approved manuscript → formats → metadata → identifiers → files → proof → distribution → release**

Skipping one stage often creates problems later.

## Why this matters

Publishing errors can come from:

- wrong metadata
- stale files
- missing permissions
- bad trim settings
- inaccessible EPUB structure
- unreviewed proofs
- inconsistent edition content

## PocketAuthor principle

The author should stay in control of:

- rights
- identifiers
- territories
- pricing
- retailer terms
- final release
