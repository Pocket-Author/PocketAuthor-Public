# Writing and Publishing a Book Is Not One Skill

Authors are often given one giant checklist.

A better model is a library of smaller workflows with clear inputs and finish lines.

## Examples of book skills

- argument mapping
- interview planning
- developmental editing
- fact checking
- source review
- metadata preparation
- accessibility review
- ARC planning
- launch calendar
- bookstore outreach
- rights tracking

## Why smaller skills help

Each skill can define:

- inputs
- output
- risk level
- review gate
- collaborator
- definition of done
