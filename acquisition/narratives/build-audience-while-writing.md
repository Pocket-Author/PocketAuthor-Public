# Build the Audience While You Build the Book

A book should not launch into silence.

Audience-building can start before publication without turning the writing process into nonstop promotion.

## During the book

Share:

- the questions you are researching
- useful frameworks
- behind-the-scenes decisions
- sourced lessons
- reader questions
- selected excerpts after approval
- workshop versions of ideas
- book-progress milestones

## Build the launch system early

Prepare:

- waitlist
- landing page
- newsletter
- ARC plan
- podcast target list
- media assets
- event outreach
- partner list
- launch calendar

## Do not promote unfinished claims as settled fact

Keep research status visible.
