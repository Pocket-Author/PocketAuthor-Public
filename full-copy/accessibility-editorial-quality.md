# Accessibility Is Part of Editorial Quality

Accessibility is often treated as compliance work that happens after the book is finished.

That is too late.

Accessibility changes how the book should be structured, described, formatted, and tested.

That makes it an editorial quality issue.

## A readable book is not readable for everyone

A beautifully designed page can still be difficult for readers who use:

- screen readers
- magnification
- large print
- alternative contrast settings
- keyboard navigation
- audio
- reflowable text

Design quality should include those readers.

## Structure matters

Clear headings are useful visually.

They are also useful semantically.

A properly structured ebook gives assistive technology a map.

That makes navigation easier.

## Images need meaning

If an image communicates information, the book needs a way to communicate that information when the image cannot be seen.

That may involve:

- alt text
- captions
- surrounding explanation

Decorative images are different.

The editorial team needs to know which is which.

## Large print is not a font-size toggle

A large-print edition may require:

- different page dimensions
- spacing
- line length
- margins
- pagination
- cover adjustments

It is a distinct reading context.

Treat it as an edition.

## Audio creates accessibility too

Some readers prefer or require audio.

That makes audiobook quality part of the accessibility conversation.

But audio also needs adaptation.

Tables, figures, and visual references may need to be rewritten for listening.

## Accessibility benefits many readers

Clear structure.

Readable typography.

Good navigation.

Useful descriptions.

These improve the book for everyone.

## PocketAuthor opportunity

Accessibility checks can become part of production rather than a final optional audit.

The project can ask:

- Are headings structured?
- Are images described?
- Is navigation clear?
- Does the EPUB validate?
- Is large print a planned edition?
- Is audio feasible?

That moves accessibility earlier.
